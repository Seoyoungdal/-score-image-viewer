나의 악보집 v1.3.0 업로드 방법

1. 이 폴더 안의 파일을 모두 GitHub 저장소의 최상위 위치에 올립니다.
2. GitHub 저장소에서 Settings → Pages로 이동합니다.
3. Source를 Deploy from a branch로 선택합니다.
4. main 브랜치와 / (root)를 선택한 뒤 Save를 누릅니다.
5. 게시 주소를 Safari에서 열고 공유 → 홈 화면에 추가를 선택합니다.

처음 실행한 뒤 '악보집 가져오기'를 눌러 최상위 악보 폴더를 선택합니다.
가져온 악보는 기기의 앱 저장공간에 복사되므로 평소에는 폴더를 다시 선택할 필요가 없습니다.
새 파일을 넣거나 이름을 바꾼 경우에만 '악보집 업데이트'로 같은 폴더를 다시 선택하세요.

주의
- Safari의 방문 기록 및 웹사이트 데이터를 삭제하면 저장된 악보도 삭제될 수 있습니다.
- GitHub Pages 주소가 변경되면 별도의 앱 저장공간으로 인식됩니다.
- 첫 실행과 앱 업데이트 확인에는 인터넷 연결이 필요합니다.
