# 나의 악보집 v1.3.1

아이패드·아이폰·PC에서 악보 이미지를 폴더별로 가져와 검색하고 오프라인으로 열람하는 웹앱입니다.

## 주요 기능

- 악보 이미지를 IndexedDB에 저장해 폴더를 매번 다시 선택할 필요가 없습니다.
- 같은 폴더를 다시 가져오면 추가·변경·삭제된 파일을 동기화합니다.
- 한글 NFC/NFD, 띄어쓰기, 밑줄, 하이픈과 특수문자를 무시하고 검색합니다.
- 아이패드에서는 악보 목록과 미리보기를 한 화면에 표시합니다.
- 시스템 설정·밝게·어둡게 테마를 지원합니다.
- 홈 화면에 추가하면 인터넷 연결 없이 앱을 다시 열 수 있습니다.

## GitHub Pages

압축 내부의 모든 파일을 저장소 루트에 올린 뒤 Settings → Pages에서 main / root를 선택합니다.

처음 실행할 때만 인터넷 연결이 필요하며, 악보를 가져온 뒤에는 오프라인으로 사용할 수 있습니다.
