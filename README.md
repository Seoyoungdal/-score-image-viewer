# 악보 이미지 뷰어

휴대폰 폴더에 저장된 악보 이미지를 번호 또는 제목으로 빠르게 찾아보는 단일 파일 웹앱입니다.

## 주요 기능

- 번호 `1~999` 및 제목 일부 검색
- 띄어쓰기, 밑줄, 하이픈을 무시하는 검색
- 같은 제목이 여러 개면 목록으로 표시
- 선택한 최상위 폴더와 모든 하위 폴더 검색
- 가로 이미지는 화면 너비, 세로로 긴 이미지는 화면 높이에 맞춰 표시
- 두 번 탭하여 전체 화면 열기/닫기
- 두 손가락 확대 지원
- 검색어 지우기 버튼
- 프로그램 이름 변경
- 폴더 재선택을 통한 새 파일 목록 새로고침
- 별도 서버와 데이터베이스 없이 휴대폰 안의 파일만 사용
- 책과 악보를 결합한 전용 앱 아이콘
- `version.json`을 이용한 최신 버전 확인 및 다운로드
- 투명 배경 PNG를 포함한 이미지의 흰색 전체 화면 표시
- 시스템 설정·밝게·어둡게 중 선택할 수 있는 화면 테마
- 웹에서 한 번 실행한 뒤 인터넷 없이 다시 열 수 있는 오프라인 캐시

## 실행 방법

1. `index.html`을 휴대폰 또는 PC에서 엽니다.
2. 오른쪽 위 **설정(⚙)**을 누릅니다.
3. **악보집 폴더 선택 / 새로고침**을 누릅니다.
4. 파일 앱에서 악보가 들어 있는 최상위 폴더를 선택합니다.
5. 번호나 제목 일부를 입력한 뒤 **검색**을 누릅니다.

### 인터넷 없이 사용하기

- PC에서는 `index.html`을 직접 열면 인터넷 없이 사용할 수 있습니다.
- GitHub Pages에서는 인터넷이 있을 때 앱을 한 번 열면 필요한 앱 파일이 저장됩니다. 이후에는 인터넷 연결이 없어도 다시 열 수 있습니다.
- 브라우저 데이터나 사이트 캐시를 삭제하면 다시 한 번 인터넷에 연결해 앱을 열어야 합니다.
- 악보 이미지는 오프라인 캐시에 복사하지 않으며, 사용자가 선택한 휴대폰 또는 PC 폴더에서 직접 읽습니다.

## 권장 폴더 구성

```text
악보집/
├─ CCM/
│  ├─ 125_주사랑이나를숨쉬게해.jpg
│  └─ 126_주의보좌로.jpg
├─ 찬송가/
│  └─ 210_시온성과같은교회.jpg
└─ 성탄절/
   └─ 301_기쁘다구주오셨네.png
```

최상위 `악보집` 폴더를 선택하면 `CCM`, `찬송가`, `성탄절` 등 하위 폴더까지 모두 검색합니다.

## 파일 이름 권장 형식

```text
번호_제목.jpg
```

예: `125_주사랑이나를숨쉬게해.jpg`

JPG, PNG, WEBP, GIF, BMP, HEIC/HEIF 파일을 대상으로 검색합니다. 브라우저에 따라 HEIC 화면 표시는 제한될 수 있습니다.

## 새 악보를 추가했을 때

브라우저는 폴더를 선택한 당시의 파일 목록을 읽습니다. 폴더에 새 이미지를 넣은 뒤에는 앱의 **설정 → 악보집 폴더 선택 / 새로고침**을 누르고 같은 폴더를 다시 선택해 주세요.

## GitHub에 올리는 방법

1. 이 폴더 안의 `index.html`과 `README.md`를 저장소에 올립니다.
2. 저장소에서 **Settings → Pages**로 이동합니다.
3. **Deploy from a branch**를 선택합니다.
4. `main` 브랜치와 `/ (root)`를 선택하고 저장합니다.

`version.json`도 반드시 함께 올려야 앱의 **최신 버전 확인** 기능이 작동합니다. 새 버전을 배포할 때는 `version.json`의 `version`, `download`, `filename` 값을 새 버전에 맞게 변경해 주세요.

홈 화면과 브라우저 아이콘이 정상 표시되도록 `icon.svg`, `icon-192.png`, `icon-512.png`, `site.webmanifest`도 함께 올려주세요. 오프라인 실행을 위해 `sw.js`도 반드시 같이 올려야 합니다.

비공개 저장소는 초대받은 GitHub 사용자만 소스를 볼 수 있습니다. GitHub Pages 공개 범위는 GitHub 요금제와 저장소 설정에 따라 달라질 수 있습니다.

## 개인정보

선택한 이미지 파일은 서버로 업로드하지 않습니다. 검색과 표시는 사용 중인 브라우저 안에서 처리됩니다.
